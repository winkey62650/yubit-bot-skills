# YUBIT Bot Skills

Telegram automation scripts for the YUBIT x Winkey community.

This project contains:

- Telegram forum topic setup and repair scripts.
- Futures and TradFi signal posters with mobile card rendering.
- Crypto and TradFi news posters.
- A 15-minute posting cycle wrapper.
- Moderator helper messages and market discussion agent scripts.
- A local HTML console for planning the community setup.

## Safety

Do not commit real Telegram bot tokens, chat IDs, `.env` files, or runtime state.
All production credentials must be passed through environment variables.

Trading, futures, and macro content generated by these scripts is informational only and is not investment advice.

## Requirements

- Node.js 20+
- Python 3
- Python package: `Pillow`

Install the Python renderer dependency:

```bash
python3 -m pip install -r requirements.txt
```

Check JavaScript syntax:

```bash
npm run check
```

## Environment

Copy `.env.example` to `.env` locally and fill only on your machine:

```bash
cp .env.example .env
```

Required for Telegram posting:

```bash
TELEGRAM_CHAT_ID="-100..."
TELEGRAM_BOT_TOKEN="123:abc"
```

The 15-minute cycle expects:

```bash
TELEGRAM_CHAT_ID="-100..."
TRADER1_BOT_TOKEN="123:abc"
```

## Run Scripts

Dry-run or console-only signal generation:

```bash
node binance-futures-sma-signal.mjs
node tradfi-market-signal.mjs
```

Post a futures signal card:

```bash
SEND_TELEGRAM=true TELEGRAM_CHAT_ID="-100..." TELEGRAM_BOT_TOKEN="123:abc" TELEGRAM_THREAD_ID=10 node binance-futures-sma-signal.mjs
```

Run the 15-minute content cycle:

```bash
TELEGRAM_CHAT_ID="-100..." TRADER1_BOT_TOKEN="123:abc" node run-15m-cycle.mjs
```

## Topic Defaults

The Winkey forum topic config uses:

- `6`: New Users
- `8`: UID Verification
- `10`: Futures Signals
- `12`: TradFi Signals
- `14`: Crypto News
- `16`: Stocks & TradFi News
- `18`: Market Discussion
- `20`: Campaigns

Adjust `winkey-agent-topics.config.json` if your Telegram forum topic IDs differ.
