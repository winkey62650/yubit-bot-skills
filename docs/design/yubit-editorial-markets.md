# VIP Market Intelligence · Wide Dense V4

The seven 1600×900 artworks in `VIP-Market-Intelligence-Wide-Dense-V4.zip` are the supplied visual family. Only the first four are active in the automated Telegram/Discord product: `01-daily-market-brief-wide-v4.png`, `02-data-flash-wide-v4.png`, `03-market-follow-up-wide-v4.png`, and `04-weekly-catalysts-wide-v4.png`. The backend renders their production equivalents at 1200×675, preserving the same 16:9 composition.

The active visual language is cool white, deep navy, cyan-blue and sparse gold. A dark gradient hero establishes the content type; glass-like white information panels carry the verified daily data; gold marks only the primary number or the highest-impact item. The canvas is dense enough to feel complete, but modules disappear when their source field is unavailable. Empty weekday cards, dash-filled metric boxes and decorative filler are forbidden.

Each product keeps its own layout and one-to-one template ID:

- `Daily Market Brief → daily-market-brief-v4`: hero title plus up to three ranked evidence cards, each with impact, affected assets and score.
- `Weekly Catalyst Calendar → weekly-catalysts-v4`: one Monday–Sunday UTC week, showing only verified material events inside that week.
- `Data Flash → data-flash-v4`: official actual first, then only available comparison fields, followed by desk read and confirmation/invalidation.
- `Market Follow-up → market-follow-up-v4`: measured reaction window, cross-asset response and a conclusion that explicitly avoids claiming causation.

Public output remains publisher-neutral. Never render YUBIT, YUBIT Academy, a logo, mascot, QR code, official-author claim, generic `1–7D` horizon, or investment-action wording. Native token glyphs may appear only as restrained asset anchors; unknown assets remain plain tickers.

Poster and text must be generated from the same canonical Obsidian live snapshot. Any mismatch in number, direction, UTC time, source or observation window blocks media delivery. In Telegram, each poster is sent immediately before its matching text. Rendering failure fails closed and never substitutes another product's artwork.
