# VIP Market Intelligence · Locked Masters

The supplied 1600×900 artworks define the visual family. Four products are active in the automated Telegram/Discord product: `01-daily-market-brief-wide-v4.png`, `02-data-flash-wide-v4.png`, `03-market-follow-up-wide-v4.png`, and the approved five-column calendar master `04-weekly-catalysts-wide-v5.png`. The backend renders their production equivalents at 1200×675, preserving the same 16:9 composition.

The active visual language is cool white, deep navy, cyan-blue and sparse gold. A dark gradient hero establishes the content type; glass-like white information panels carry the verified daily data; gold marks only the primary number or the highest-impact item. The canvas is dense enough to feel complete, but modules disappear when their source field is unavailable. Empty weekday cards, dash-filled metric boxes and decorative filler are forbidden.

Each product keeps its own layout and one-to-one template ID:

- `Daily Market Brief → daily-market-brief-v4`: hero title plus up to three ranked evidence cards, each with impact, affected assets and score.
- `Weekly Catalyst Calendar → weekly-catalysts-v5`: one Monday–Friday UTC workweek on the poster. Each day keeps one highest-priority primary catalyst plus up to two current, sourced secondary watches. The underlying content model retains the full Monday–Sunday week so weekend crypto events remain available to the paired text product.
- `Data Flash → data-flash-v4`: official actual first, then only available comparison fields, followed by desk read and confirmation/invalidation.
- `Market Follow-up → market-follow-up-v4`: measured reaction window, cross-asset response and a conclusion that explicitly avoids claiming causation.

Public output remains publisher-neutral. Never render YUBIT, YUBIT Academy, a logo, mascot, QR code, official-author claim, generic `1–7D` horizon, or investment-action wording. Native token glyphs may appear only as restrained asset anchors; unknown assets remain plain tickers.

Poster and text must be generated from the same canonical Obsidian live snapshot. Any mismatch in number, direction, UTC time, source or observation window blocks media delivery. Secondary watches must have an explicit current source and stay inside the same week; they are never invented merely to increase density. In Telegram, each poster is sent immediately before its matching text. Rendering failure fails closed and never substitutes another product's artwork.
