# Telegram Academy Asset Generator

This generator creates a full Telegram decoration pack for a trading academy-style agent community.

## What It Generates

- `01-welcome-banner-1280x720.png`: group welcome / pinned hero
- `02-channel-cover-1280x720.png`: Telegram channel cover
- `03-uid-verification-1080x1080.png`: UID verification flow
- `04-onboarding-flow-1080x1350.png`: full access flow
- `05-telegram-channel-system-1280x720.png`: channel / verify bot / premium system
- `06-weekly-schedule-1080x1350.png`: weekly academy content rhythm
- `07-trust-rules-1080x1350.png`: risk and anti-scam trust rules
- `08-content-matrix-1280x720.png`: education / signals / live events / community matrix
- `09-telegram-funnel-1280x720.png`: full funnel map

## Agent Config

Copy `config/academy-agent.example.json` and edit it for each agent.

```json
{
  "brand": "YUBIT",
  "agent": "Ricky",
  "academy": "Ricky Trading Academy",
  "handle": "@ricky_yubit",
  "subscribers": "1,221",
  "photo": "assets/agents/ricky.png",
  "palette": "cyan_gold",
  "promise": "Daily market context, verified onboarding, and a repeatable trading routine.",
  "cta": "START WITH UID VERIFICATION",
  "bot_name": "YUBIT Verify Bot",
  "channel_name": "Ricky Academy",
  "premium_name": "Ricky Academy PREMIUM"
}
```

`photo` can be absolute, or relative to the config file. If empty or missing, the generator uses the agent initial as a clean placeholder.

## Generate

```bash
python3 scripts/render-academy-assets.py \
  --agent-config config/academy-agent.example.json \
  --out-dir generated/academy-assets/ricky
```

Override palette without editing the config:

```bash
python3 scripts/render-academy-assets.py \
  --agent-config config/academy-agent.example.json \
  --palette emerald_platinum \
  --out-dir generated/academy-assets/ricky-emerald
```

List palettes:

```bash
python3 scripts/render-academy-assets.py --list-palettes
```

## Five Premium Palettes

- `cyan_gold`: neon cyan + trading gold + red alert
- `emerald_platinum`: premium green + platinum + warm gold
- `royal_violet`: violet + electric cyan + magenta accent
- `graphite_lime`: graphite black + lime + blue
- `sapphire_copper`: sapphire blue + copper + mint

## Design Notes

- Background pattern uses the agent name, not `YUBIT`, so each pack feels owned by the agent.
- All important text is rendered with Pillow, not generated by an AI image model, so labels stay readable and consistent.
- The same config drives every asset, which makes this suitable for batch production.
